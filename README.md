# cuidarplus-software-engineering

Entregável da disciplina de Engenharia de Software (FIAP, Global Solution 2026-2), com a documentação de arquitetura da solução Neighborhood Action Dashboard (projeto CuidarPlus).

## Estrutura

```
contexto/       enunciado resumido, decisões fechadas e rastreabilidade RF/RNF
docs/           entregável, um arquivo por seção do enunciado
  05-adr/       registros de decisões arquiteturais
referencias/    materiais de apoio (fora do Git, ver .gitignore)
```

## Como usar

Antes de começar, leia `contexto/decisoes.md`, que é a fonte de verdade das escolhas do projeto.
